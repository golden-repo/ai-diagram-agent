# File Naming Convention

All files related to a single workflow session use a common **Session ID** (8-character UUID).

## Naming Patterns

### Logs: `{session_id}_{type}_iter{N}.{ext}` (keeps iteration history)
### Output: `{session_id}_diagram.{ext}` (final version only, overwrites)

### Example Session: `a3f7b2c9`

```
logs/
├── a3f7b2c9_plan_iter0.txt          # Initial plan
├── a3f7b2c9_plan_iter1.txt          # Revised plan after feedback
├── a3f7b2c9_review_iter1.txt        # Review of iteration 1
├── a3f7b2c9_review_iter2.txt        # Review of iteration 2
└── a3f7b2c9_review_iter3.txt        # Review of iteration 3

output/
├── a3f7b2c9_diagram.drawio          # Final Draw.io diagram (open in app.diagrams.net)
├── a3f7b2c9_diagram.mmd             # Final Mermaid diagram (plain text)
├── a3f7b2c9_diagram.html            # Mermaid HTML viewer (open in browser)
└── a3f7b2c9_diagram.png             # Final rendered image
```

## File Types

### Logs (`logs/` folder) - Iteration History
- **Plan files**: `{session_id}_plan_iter{N}.txt`
  - Contains diagram type and step-by-step plan
  - Generated by Planning Agent
  - Keeps all iterations to track improvements
  
- **Review files**: `{session_id}_review_iter{N}.txt`
  - Contains review feedback and full generated code
  - Generated by Reviewer Agent
  - Keeps all iterations to track feedback

### Output (`output/` folder) - Final Results Only
- **Draw.io diagrams**: `{session_id}_diagram.drawio`
  - XML format, open in https://app.diagrams.net
  - Generated by Draw.io Worker
  - Overwrites on each iteration (only final version kept)
  
- **Mermaid diagrams**: `{session_id}_diagram.mmd`
  - Plain text Mermaid syntax
  - Generated by Mermaid Worker
  - Overwrites on each iteration (only final version kept)
  
- **Mermaid HTML viewer**: `{session_id}_diagram.html`
  - Self-contained HTML file with embedded Mermaid
  - Open directly in any web browser
  - No additional tools needed!
  
- **Images**: `{session_id}_diagram.png`
  - Rendered PNG image (Mermaid only)
  - Generated by Image Gen Agent
  - Overwrites on each iteration (only final version kept)

## How to View Diagrams

### Mermaid Diagrams
1. **Easiest**: Open `{session_id}_diagram.html` in your browser
2. **Alternative**: Open `{session_id}_diagram.png` image
3. **Edit**: Open `{session_id}_diagram.mmd` in VS Code with Mermaid extension

### Draw.io Diagrams
1. Go to https://app.diagrams.net
2. Click "Open Existing Diagram"
3. Select `{session_id}_diagram.drawio`
4. Edit and export as needed

## How to Track a Session

1. **Find Session ID**: Check console output when workflow starts
   ```
   🚀 Starting new workflow - Session ID: a3f7b2c9
   ```

2. **View final diagram**: Open `output/a3f7b2c9_diagram.html` (Mermaid) or `output/a3f7b2c9_diagram.drawio` (Draw.io)

3. **Review workflow progression**:
   - Read `logs/a3f7b2c9_plan_iter0.txt` - initial plan
   - Read `logs/a3f7b2c9_review_iter1.txt` - first review feedback
   - Continue through iterations to see improvements

## Benefits

✅ **Easy tracking**: All files from one session grouped by ID
✅ **Iteration history**: Logs show how diagrams evolved
✅ **Clean output**: Only final diagrams in output folder
✅ **No tools needed**: HTML viewer for Mermaid, web viewer for Draw.io
✅ **Debugging**: Compare plan → review feedback across iterations
